# نظام متابعة العملاء — محفظة جيب

تطبيق ويب للموظفين — **بدون SQL** — التخزين على IndexedDB في المتصفح.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:5173
```

## تسجيل الدخول (افتراضي)

| المستخدم | كلمة المرور | الدور |
|----------|-------------|-------|
| `admin` | `1234` | مدير |
| `mohammed` | `1234` | موظف (محمد) |
| `sara` | `1234` | موظف (سارة) |
| `naif` | `1234` | موظف (نايف) |

غيّر كلمات المرور من **الإعدادات**.

---

## للموظف المبتدئ — ابدأ من هنا

1. **سجّل دخول** باسمك وكلمة المرور
2. **عملي اليوم** — الصفحة الرئيسية:
   - بحث سريع بالكود أو الجوال
   - زر **متابعة** — حقلان فقط (ماذا فعلت + موعد)
   - زر **إضافة عميل** — 4 حقول فقط
3. **Excel** — ارفع ملف Excel الحالي دفعة واحدة

---

## استيراد Excel

1. اذهب إلى **Excel** من القائمة
2. **تحميل نموذج فارغ** (اختياري) أو ارفع ملفك الحالي
3. النظام يتعرف على الأعمدة العربية تلقائيًا:
   - كود العميل · رقم الجوال · اسم الشبكة · حالة المرفقات · ...
4. **معاينة** ثم **استيراد**
5. إذا الكود موجود: **حدّث** (موصى به) أو **تخطّى**

## التخزين

| | |
|---|---|
| **أين؟** | IndexedDB في المتصفح (نفس المشروع — لا سيرفر) |
| **السعة** | آلاف العملاء |
