# رفع النظام على سيرفر الشركة (بيانات مشتركة + صلاحيات)

## ماذا ستحصل؟

| الرابط | من يستخدمه |
|--------|------------|
| `http://IP-السيرفر:5173/login` | **موظفو الدعم** — تسجيل دخول |
| `http://IP-السيرفر:5173/studio` | **الموظف** — تصميم القوالb |
| `http://IP-السيرفر:5173/design` | **العملاء** — تصميم بدون دخول |
| `http://IP-السيرفر:5173/my-work` | **الموظف** — عملي اليوم |

- **كل الموظفين** يرون **نفس بيانات العملاء** (ملف واحد على السيرفر)
- **المدير** يدير المستخدمين من الإعدادات
- **الموظف** يرى العملاء ويعمل عليهم حسب صلاحياته
- **بيانات العملاء محمية** — لا تُقرأ إلا بعد تسجيل الدخول

---

## 1) تجهيز الحزمة (على جهازك)

```bash
cd web
npm run package:server
```

النتيجة: مجلد `web/deploy/server-package/`

---

## 2) رفع على سيرفر Windows

1. انسخ مجلد **`server-package`** كاملاً إلى السيرفر (مثلاً `C:\Apps\CustomerPortal\`)
2. ثبّت **Node.js 20+** على السيرفر: https://nodejs.org
3. انقر مرتين: **`تشغيل-السيرفر.bat`**
4. افتح من أي جهاز في الشبكة:  
   `http://عنوان-السيرفر:5173/login`

> **مهم:** لا تفتح `index.html` مباشرة — شغّل السيرفر دائماً.

---

## 3) رفع على Linux (اختياري)

```bash
cd /opt/customer-portal
npm ci --omit=dev
APP_MODE=production NODE_ENV=production node server/index.js
```

استخدم **systemd** أو **pm2** للتشغيل الدائم.

---

## 4) الأمان (بيانات حساسة)

1. **شبكة داخلية فقط** — لا تفتح المنفذ 5173 على الإنترنت العام
2. **HTTPS** — استخدم Nginx/IIS كـ reverse proxy مع شهادة SSL
3. **نسخ احتياطي يومي** لملف:  
   `server/data/store.json`
4. **غيّر كلمات المرور** من الإعدادات بعد أول رفع
5. **صلاحيات الملفات** — `store.json` قراءة/كتابة للسيرفر فقط

---

## 5) حسابات الدخول

> **لا تظهر في واجهة النظام** — سلّمها للموظفين بشكل خاص (واتساب/ورقة).

| الدور | اسم المستخدم | الصلاحيات |
|-------|--------------|-----------|
| مدير / دعم فني | `777465157` | كل الصلاحيات + إدارة المستخدمين |
| موظف | `user1` | عمل العملاء والتصميم |
| مدير احتياطي | `admin` | كل الصلاحيات |

**كلمة المرور الافتراضية:** `1234` — **غيّرها فوراً** من الإعدادات.

---

## 6) إضافة موظف جديد

1. سجّل دخول كـ **مدير** (`777465157` أو `admin`)
2. **الإعدادات** → إضافة مستخدم
3. اختر الدور: **موظف** أو **مدير**

---

## 7) تحديث النسخة

1. على جهازك: `npm run package:server`
2. أوقف السيرفر
3. استبدل مجلد `dist` و `server/index.js` و `server/auth.js`
4. **لا تحذف** `server/data/store.json`
5. أعد التشغيل

---

## 8) استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| صفحة بيضاء | شغّل `تشغيل-السيرفر.bat` — لا تفتح HTML مباشرة |
| لا يقبل الدخول | شغّل `node scripts/seed-users.mjs` |
| بيانات لا تظهر | تأكد من تسجيل الدخول — البيانات محمية |
| القوالb بدون صور | تأكد من وجود `public/netcard/templates/template*.jpg` |

---

## الدعم

- ملف البيانات: `server/data/store.json`
- صحة السيرفر: `http://localhost:5173/api/health`
