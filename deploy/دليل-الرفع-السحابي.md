# رفع مصمم البطاقات على الإنترنت (للعملاء)

## الفكرة

| الرابط | من يستخدمه | ماذا يرى |
|--------|------------|----------|
| `https://موقعك.com/` أو `/design` | **العميل / الزائر** | تصميم فقط — بدون تسجيل، بدون اختيار عميل من القاعدة |
| `https://مويتك.com/login` | **الموظف** | تسجيل دخول ثم كل الخدمات (عملي اليوم، ردود، شبكات، …) |
| `/studio` | **الموظف بعد الدخول** | التصميم مع بحث العميل واستيراد Excel |

---

## 1) رفع المشروع على GitHub

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `mahfazat-jeeb-design`).
2. من مجلد `web` على جهازك:

```bash
git init
git add .
git commit -m "مصمم بطاقات محفظة جيب — نسخة سحابية"
git branch -M main
git remote add origin https://github.com/USERNAME/mahfazat-jeeb-design.git
git push -u origin main
```

> **مهم:** لا ترفع ملفات `server/data/store.json` إن كانت تحتوي بيانات موظفين — أضفها إلى `.gitignore`.

---

## 2) النشر على Render (مجاني)

1. ادخل [render.com](https://render.com) وسجّل بحساب GitHub.
2. **New → Blueprint** أو **New Web Service**.
3. اختر المستودع الذي رفعته.
4. Render يقرأ `render.yaml` تلقائياً، أو اضبط يدوياً:
   - **Build:** `npm install && npm run build`
   - **Start:** `APP_MODE=production NODE_ENV=production node server/index.js`
5. بعد النشر ستحصل على رابط مثل:  
   `https://mahfazat-jeeb-design.onrender.com`

---

## 3) مشاركة الرابط مع العملاء

- **للعملاء (التصميم فقط):**  
  `https://موقعك.onrender.com/design`  
  أو الصفحة الرئيسية `/` — تفتح التصميم مباشرة.

- **للموظفين:**  
  `https://مويتك.onrender.com/login`  
  ثم يعملون كالعادة. التصميم للموظف من القائمة: **قالب التصميم** (`/studio`).

---

## 4) التثبيت المحلي للموظفين (كما هو)

- استمر في توزيع **MahfazatJeeb-Installer.zip** على أجهزة الدعم.
- النسخة المحلية تعمل بدون إنترنت وتخزن كل العملاء على الجهاز.
- النسخة السحابية للعملاء الذين يريدون تصميم بطاقتهم بأنفسهم فقط.

---

## 5) اختبار قبل المشاركة

```bash
npm run build
set APP_MODE=production
set NODE_ENV=production
node server/index.js
```

افتح `http://localhost:5173/design` — يجب أن ترى:
- اختيار/رفع قالب
- حقول: اسم الشبكة، الكود، الهاتف
- **بدون** مربع «اختيار العميل»

افتح `/login` وسجّل دخول موظف — يجب أن يفتح `/my-work` والتصميم من `/studio`.

---

## بدائل أخرى

- **Railway.app** — نفس أوامر البناء والتشغيل.
- **VPS** — `npm run build` ثم `APP_MODE=production node server/index.js` خلف nginx.

GitHub Pages **لا يكفي** لأن التطبيق يحتاج خادم Node (Express) لخدمة الواجهة وAPI.
