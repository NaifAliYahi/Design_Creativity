# دليل توزيع النظام على أجهزة الدعم الفني

## ماذا يحتاج كل جهاز؟

| المطلوب | مرة واحدة أم يومياً؟ | الرابط / الملاحظة |
|---------|---------------------|-------------------|
| **Node.js LTS** | مرة واحدة فقط | https://nodejs.org — اختر **LTS** وثبّت بالإعدادات الافتراضية |
| **مجلد النظام** | ينسخ من المدير | مجلد `web` كامل بعد البناء |
| **install-once.bat** | مرة واحدة فقط | يثبت المتطلبات + ينشئ أيقونة سطح المكتب |
| **أيقونة سطح المكتب** | كل يوم — نقرة واحدة | «محفظة جيب - كروت الشبكات» |

> **لا يحتاجون:** Visual Studio، Python، Git، أو أي بيئة برمجة.

---

## خطوات المدير (مرة واحدة — عندك)

1. افتح مجلد `web`
2. شغّل **`prepare-package.bat`** — يبني النسخة الجاهزة
3. انسخ المجلد كاملاً إلى **فلاشة** أو **شبكة مشتركة** أو **ZIP**
4. المجلدات المطلوبة في النسخة:
   - `dist/` — التطبيق الجاهز
   - `server/` — قاعدة البيانات
   - `public/` — القوالب والصور
   - `scripts/` — سكربت الاختصار
   - `package.json`
   - `run-app.bat`
   - `install-once.bat`

يمكن حذف `src/` و `node_modules/` من النسخة لتقليل الحجم — يُعاد تثبيت `node_modules` على كل جهاز.

---

## خطوات الموظف (أول مرة على جهاز جديد)

1. **ثبّت Node.js**
   - ادخل https://nodejs.org
   - حمّل **LTS** (الزر الأخضر)
   - Next → Next → Install → Finish

2. **انسخ مجلد النظام** إلى مكان ثابت، مثلاً:
   ```
   C:\MahfazatJeeb\NetworkCards\
   ```

3. **شغّل `install-once.bat`** (نقر مرتين)
   - ينتظر حتى ينتهي
   - يظهر: «Setup complete!»

4. **ستجد على سطح المكتب:**
   - `محفظة جيب - كروت الشبكات`

---

## الاستخدام اليومي (كل موظف)

1. **نقرة واحدة** على أيقونة سطح المكتب
2. يفتح المتصفح تلقائياً على: `http://localhost:5173`
3. **لا تغلق** النافذة السوداء أثناء العمل
4. سجّل دخول: `admin` / `1234` أو حسابك

## حل المشاكل

| المشكلة | الحل |
|---------|------|
| «Node.js is not installed» | ثبّت Node.js ثم أعد `install-once.bat` |
| الصفحة لا تفتح | تأكد أن النافذة السوداء مفتوحة — شغّل الأيقونة مرة أخرى |
| المنفذ مشغول | أغلق أي نافذة سوداء قديمة للنظام |
| `dist folder missing` | اطلب من المدير نسخة كاملة فيها مجلد `dist` |
